# Wireframe and UI direction

## Main storefront
```text
+------------------------------------------------------------------+
| TechStore                       Products  My orders  Cart  Login |
+------------------------------------------------------------------+
| TECH / LIFESTYLE                                                  |
| Upgrade your tech setup.                    [Illustrative device] |
| Intro copy + [Explore products]                                   |
+------------------------------------------------------------------+
| Featured products                              N products         |
| [Search________________] [Category v] [Search]                    |
| +----------------+ +----------------+ +----------------+          |
| | Product image  | | Product image  | | Product image  |          |
| | Category       | | Category       | | Category       |          |
| | Name           | | Name           | | Name           |          |
| | Price [Add]    | | Price [Add]    | | Price [Add]    |          |
| +----------------+ +----------------+ +----------------+          |
+------------------------------------------------------------------+
| Footer: project / stack / copyright                               |
+------------------------------------------------------------------+
```

## Reference and rationale
The storefront uses a prominent search/filter area and clear product cards. It borrows general usability principles from booking and commerce interfaces (strong hierarchy, obvious search, responsive cards), not Booking.com's branding or assets.

## Responsive behavior
- Desktop: 3–4 product cards per row.
- Tablet: 2 cards per row.
- Mobile: 1 card per row; navigation collapses.
- Modals are used for login/register, cart and order history.
